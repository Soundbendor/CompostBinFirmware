# Architecture Decision Records

Use ADRs for decisions that affect component boundaries, protocols, persistent data, deployment compatibility, or contributor/agent workflow.

## Format

Create `NNNN-short-title.md` with:

- status and date;
- context and constraints;
- decision;
- consequences and rejected alternatives;
- compatibility, rollout, and rollback when applicable.

Do not rewrite accepted history. Supersede an ADR with a new numbered record and link the two.
